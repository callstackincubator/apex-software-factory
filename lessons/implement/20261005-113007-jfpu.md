Before reporting a branch, test mergeability with 'git merge-tree --write-tree --name-only HEAD origin/main'. If it prints CONFLICTING, merge origin/main in, resolve keeping both sides' features, re-run pnpm check and push: merge-pr.sh refuses a PR GitHub calls CONFLICTING, so a green branch that drifted behind main is not deliverable.
