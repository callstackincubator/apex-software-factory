A jest.mock factory runs while the test file's imports run, so it may only touch globals: type annotations inside it must not name a local type alias, and a mock holder declared with const below is in TDZ. To fake a hook the module under test imports (e.g. expo-router's useFocusEffect), install the control object on globalThis inside the factory and read it back through a lazy helper, and call appduct handlers as handler(args as never, undefined as never) per agent-tools/__tests__/tools.test.ts.
